# Payroll Manager

기준 버전 **v0.94.6** · 배포일 **2026년 11월 19일** · Windows 64비트 데스크톱 프로그램

Payroll Manager는 한국 급여 실무에서 사용하는 인사정보, 급여대장, 4대보험 고지내역, 퇴직급여와 원천세 집계 자료를 관리한다. 급여 처리의 기본 단위는 지급월과 지급차수다. 담당자가 계산 대상을 정하고 결과를 검토한 뒤 급여대장에 반영한다. 이미 작성한 급여대장을 엑셀로 가져오는 방식도 지원한다.

## 업무별 기능과 범위

| 업무 | 프로그램에서 처리하는 내용 | 사용 시 확인할 사항 |
| --- | --- | --- |
| 인사·연봉 | 사원정보, 부양가족, 급여계좌, 근태·휴가, 조직·직급 이력, 연봉계약을 등록한다. 연봉계약에는 산정 당시의 직급코드를 기록할 수 있다. | 직급이력과 연봉계약의 직급코드는 별도 기록이다. 확정한 연봉계약을 수정하려면 먼저 확정을 취소한다. |
| 급여 | 대상자를 선택해 수당·공제·차인지급액을 계산하고 급여대장에 반영한다. 월별·기간별 대장, 사원·부서별 집계, 기간 간 변동을 조회하고 급여명세서를 출력한다. | 계산과 대장 반영은 별도 단계다. 연봉계약, 근태, 지급·공제 항목 설정과 적용할 간이세액표가 계산 결과에 영향을 준다. |
| 급여이체 | 지급월·차수별로 사원, 은행, 계좌번호, 예금주, 이체금액을 명세서로 저장·확정하고 엑셀로 출력한다. | 이후 계좌가 바뀌어도 저장 당시 값을 조회한다. 월·차수당 저장본은 한 건이며, 다시 작성해 저장하면 교체된다. 실제 송금은 은행에서 처리한다. |
| 4대보험 | 가입정보를 관리하고 공단 고지 파일을 사업장 관리번호별로 등록한다. 파일 여러 개를 일괄 저장하고, 가입자별 월별 금액·기간 합계와 급여 공제액 차이를 조회한다. | 공단에서 받은 파일이 필요하다. 같은 지급월·관리번호·보험의 재업로드는 해당 범위의 기존 자료를 교체한다. 업로드 전 파일 범위와 공단 원본 합계를 확인한다. |
| 퇴직급여 | 평균임금·통상임금 기준 퇴직금을 비교하고, 중간정산·퇴직 지급 건, 확정급여형(DB) 추계액, 확정기여형(DC) 부담금을 관리한다. | 통상임금 산입 항목과 소정근로시간을 확인해야 한다. 담당자는 계산된 통상시급과 지급액을 조정할 수 있으며, 조정한 금액을 기준으로 세액을 다시 계산한다. |
| 기타소득·신고·보상 | 사업소득·기타소득 지급 자료와 총보상 내역을 관리한다. 급여·퇴직·사업·기타소득을 집계해 원천징수이행상황신고서를 저장·출력한다. | 신고서는 귀속월·지급월·신고구분별로 관리한다. 프로그램 안에서 신고서를 저장한 사실만으로 세무 당국의 접수가 확인되지는 않는다. |

## 데이터 저장과 운영

| 사용 방식 | 저장 위치와 운영 조건 |
| --- | --- |
| 로컬 DB | Windows PC의 암호화된 DB 파일을 사용한다. DB 파일과 비밀번호는 사용자가 관리한다. |
| NAS 공유 폴더 | SMB 공유 폴더의 DB를 선택하면 프로그램이 작업권을 확보하고 로컬 사본을 준비한다. 종료하거나 사업장을 변경할 때 변경본을 반납한다. 같은 파일을 여러 사용자가 동시에 편집하는 방식에는 제약이 있다. |
| PostgreSQL 서버 DB | 관리자가 서버, 업무 DB, 접속 권한과 인증서를 준비한다. Windows 앱에서 기존 업무 스키마에 연결하거나 로컬 DB를 새 스키마로 이관한다. PC에 저장한 연결을 여는 비밀번호와 PostgreSQL 계정 비밀번호는 별도로 관리한다. |

## v0.94.6 사용 시 확인할 한계

- **고용·산재보험 엑셀 양식** — 고용보험에서 두 줄 헤더의 상위 제목이 여러 칸에 반복되는 파일은 필요한 열을 찾지 못할 수 있다. 산재보험은 정산보험료 열이 있는 달에 읽은 금액이 원본 합계와 다를 수 있다. 두 양식의 판독 수정은 v0.94.6 이후 작업본에 반영됐다.
- **계산 검증** — v0.94.6 배포 시 관련 회귀 테스트 127개와 Windows 패키지 실행 검사를 통과했다. 별도 급여 계산 테스트 4건은 테스트용 간이세액표 누락으로 실패했고 이전 버전에서도 같은 결과가 재현됐다. 이 4건의 계산 결과는 해당 테스트로 확인하지 못했다.
- **서버 운영 검증** — v0.94.6 배포 시 실제 PostgreSQL 서버를 이용한 검증은 수행하지 않았다. 서버 도입 시에는 해당 환경에서 접속·자료 이관·조회·저장과 백업 복구를 확인해야 한다.
